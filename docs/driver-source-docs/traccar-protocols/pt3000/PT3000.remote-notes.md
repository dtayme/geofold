# PT3000 Remote Documentation Notes

Source URL: https://www.traccar.org/protocol/5045-pt3000/PT3000.pdf

The local `PT3000.pdf` file is compressed enough that raw string extraction does
not expose the protocol examples. The remote Traccar PDF renderer was readable
on 2026-06-12.

Relevant protocol evidence:

- The document identifies command `N02` as the request that returns IMEI plus
  GPRMC data.
- The example response starts with `%<imei>,$GPRMC,...`.
- The response includes a trailing message code `N028d`.
- The current archived Java and Groovy framing of `readUntil("d")` is therefore
  consistent with the documented example for the parsed PT3000 GPRMC response.

Keep the full PDF as the authoritative source. This note exists only to preserve
the remotely readable extraction point for future local audits.
